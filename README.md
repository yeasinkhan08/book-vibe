# Book vibe - Books website

A modern book website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Browse available books
- View detailed book information
- Mark books as read
- Add books to wishlist
- Read and Wishlist tabs
- Responsive design

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```
